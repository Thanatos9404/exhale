# Security

How Exhale protects its users, its API keys and its AI budget. Every control below names the file that implements it and the test that proves it. The last section lists what these controls do not cover.

## Privacy: where household data goes

- **Stored only in the browser.** The household profile, chat history and saved plans are kept in local storage, validated with zod when read back, and deleted by one button in Settings. There are no accounts, cookies, analytics or third-party scripts.
- **Sent when you ask for AI.** Deploying a routine or asking the assistant sends the household profile and the question to the Exhale API, which forwards them to Google's Gemini API, or to Anthropic's API when Gemini is unavailable. The assistant page says so next to the question box.
- **Not kept by the server.** The API holds requests in memory only for as long as it takes to answer. The plan cache is keyed on a hash of the prompt and stores the explanation text, not the request.
- **Rounded location.** Coordinates are rounded to two decimal places, about 1 km, before any request leaves the browser ([src/lib/air/openMeteo.ts](src/lib/air/openMeteo.ts)).
- **The community bulletin carries no household data.** It is built from a type that contains only public facts about the air, and a test proves that names, conditions and doses cannot reach it ([src/lib/community/advisory.ts](src/lib/community/advisory.ts), [src/lib/community/advisory.test.ts](src/lib/community/advisory.test.ts)).

## What these controls do not cover

- **Limits are per server instance.** Rate limits, the provider budgets and both caches live in function memory. A new instance starts with fresh counters, so the limits bound cost per instance rather than globally. A shared store would be needed for a global cap.
- **Inline styles are allowed.** `style-src` includes `'unsafe-inline'` because the animation and toast libraries set style attributes at runtime. Scripts get no such exception.
- **The app trusts its providers.** Text sent to Gemini or Claude is handled under those providers' terms.
- **No authentication.** There is nothing to log in to, so there is no session to steal, and also no per-user quota beyond the per-client limits above.

## Reporting a vulnerability

Please report vulnerabilities privately to the maintainer through the contact options on [their GitHub profile](https://github.com/Thanatos9404) rather than opening a public issue. Include steps to reproduce and the impact you observed. The same contact is published in [public/.well-known/security.txt](public/.well-known/security.txt).

Only the `main` branch, deployed at https://exhale-air.vercel.app, receives fixes.
